# مدونتي — موقع عربي للكتابة والخواطر

واجهة عربية متجاوبة مستوحاة من ألوان وطابع المرجع المرفق: الأبيض الدافئ، البني، والذهبي، مع شعار SVG ومعاينة هاتف مرسومة باستخدام HTML وCSS.

## تشغيل الموقع

1. فك ضغط المشروع إن كان بصيغة ZIP.
2. افتح مجلد `mdawanati-github` في Visual Studio Code.
3. افتح `index.html` في المتصفح، أو استخدم إضافة Live Server.

لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم خلفي.

## رفعه على GitHub Pages

1. أنشئ مستودعًا جديدًا (Repository) في حساب GitHub.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، بحيث يكون `index.html` في الجذر مباشرة.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، وبعدها اضغط **Save**.
5. انتظر اكتمال النشر، ثم افتح رابط GitHub Pages الذي يظهر في صفحة Pages.

## الملفات

- `index.html` — بنية الصفحة ومحتواها.
- `css/style.css` — الألوان، الخطوط، التخطيطات، التأثيرات والتجاوب مع الشاشات.
- `js/main.js` — قائمة الهاتف، نافذة المعاينة، التحقق من البريد والتنبيهات.
- `images/logo.svg` — الشعار المتجهي.
- `404.html` — صفحة الخطأ عند فتح رابط غير موجود.

## ملاحظة مهمة

هذه نسخة واجهة أمامية جاهزة للعرض والنشر على GitHub Pages. نموذج البريد تجريبي ويعرض تنبيهًا فقط؛ حفظ البريد، تسجيل المستخدمين وتسجيل الدخول الحقيقي تحتاج إلى ربط بخادم أو خدمة نماذج/قاعدة بيانات.

الخطوط تُحمّل من Google Fonts عند توفر اتصال بالإنترنت، مع خطوط بديلة في حال عدم توفرها.
